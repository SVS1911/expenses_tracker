# Expense Tracker

## Run

npx json-server --watch db.json --port 3000

## Open

views/register.html

## Flow

Register
   ↓
Login
   ↓
Dashboard
   ↓
Logout

## Features

- Add expense
- Edit expense
- Delete expense
- Search expenses
- Filter by category
- Filter by date
- Filter by a date range
- Total expense
- Category-wise expense
